- the app title should be stylized as "BioLoop" instead of "bioloop" when installed
- the metric/imperial toggle on the onboarding screen and goals screen should apply globally (perhaps as a user preference that we store).  currently you set imperial when entering your information, but when you go to the bodyweight tab, it displays in metric.  additionally, conversions should be rounded to 2 decimal places when displayed.  internally they should be stored with arbitrary precision.
- the goals tab does not load the users's height in imperial if that's their selected option.  you currently have to click metric to make it load, and then when you click imperial again, then it loads.  this is just annoying.  both should load upfront.
- we need to make units of serving sizes arbitrary.  currently we only support grams which doesn't work.  the user should be able to select the unit from a dropdown of common units for serving sizes, but they should also be able to select "custom units" and manually enter an arbitrary string.  additionally, we should get away from using "servings" as the unit for entering amounts, instead we should put the focus on the quantity of unit of the serving size when entering.  one of the issues the sole focus on grams causes is that if the serving size comes from the open foods API and it is not in grams, it prevents the user from entering the exact amount (in whatever unit that thing is measured in)
- we need to add the ability for the user to manually delete logged food items in case they log something by mistake
- need to be able to log bodyweight in units of choice (metric/imperial)
- after resetting data and going back through the onboarding flow, the bodyweight tab says "no entries yet" until the app is fully restarted.
- similar to above, when creating a recipe, the base unit of an ingredient that we allow the user to manipulate should NOT be the number of servings, but instead it should be the unit that the serving size is measured in.
- saving goal weight on the goals screen is messed up, probably on the onboarding screen too.  currently when i set the goal weight to 100lb, save, switch tabs, then switch back, for some reason the goal weight becomes ~45.4.  There's something funky going on here.
- when entering ANY measurement that could be imperial/metric, we should treat whichever one of those is currently selected as the "authoritative intent" of the user (IE 100lb converted to metric and back to imperial results in 100.1 due to rounding, but because the user selected imperial, we should treat 100lb as authoritative)
- the log tab should display recently logged foods for quick access without searching.  it should do them in order of recency.
